# Component Library

This is a component library built with React, Vite, and Storybook.

## How to run

1.  Build the Docker image:
    ```bash
    docker build -t nguyen_sunrise_coding_assignment12 .
    ```
2.  Run the Docker container:
    ```bash
    docker run -p 8083:8083 --name nguyen_sunrise_ui_garden nguyen_sunrise_coding_assignment12
    ```
3.  Open your browser and navigate to `http://localhost:8083`.
